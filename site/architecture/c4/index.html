    System Architecture

    PyMonitor follows a C4 model view. All diagrams render via Kroki PlantUML (http://localhost:8080). Click any image to zoom.

    Level 1 - System Context

    Shows how PyMonitor fits between the ALS user/caregiver, Telegram, and Windows hardware/services.

    Key point: PyMonitor is the only system you deploy. Everything else is external and accessed via existing Windows/Telegram APIs. It requires Administrator for sc stop/start.

    Level 2 - Containers

    Decomposes the Windows app into its runtime containers.

    Container Responsibilities

    Container File Role
    MetricsService app/services/metrics.py 7 decorated pollers, each while True sleep check_interval (default 10s), emit Event on status flip
    PyAgent app/services/pyagent.py Splits into active_monitoring (Event queue) and passive_monitoring (Request queue)
    MessengerService app/services/messenger.py Holds list[MessageInterface], currently only TelegramInterface
    TelegramInterface app/services/interfaces.py Application.builder().token().build(), handlers, TelegramError retry 360s
    AlarmService app/services/alarm.py Per-resource asyncio.Event + Task, -nok.mp3 loop, -ok.mp3 once
    StateManager app/services/database.py dict[str, Event], get returns dummy Event(status=None) to force first emission
    Settings app/settings.py PYMONITOR__ env, base_path/assets_path/root_path computed fields

    Zooms into MetricsService and PyAgent.

    Deployment View (Informal)

    PyMonitor runs as a single Windows process (main.py):

    main.py
  -> asyncio.Queue (event_queue)
  -> asyncio.Queue (request_queue)  # internal to PyAgent/MessengerService
  -> StateManager()  # shared between MetricsService and PyAgent
  -> MetricsService().set_event_queue().set_state_tracker()
  -> MessengerService.initialize(queue=request_queue)
  -> PyAgent(messenger).set_event_queue().set_state_tracker()
  -> PyMonitor(metric_collector, agent, event_queue, state).start()
     -> gather(metrics.start() [7 coroutines], agent.start() [messenger + active + passive])

    Built to a single .exe via pyinstaller --name PyMonitor -p .\app\ main.py --noconsole --onefile (frozen base_path via sys.executable). Logs to app.log beside the exe.
